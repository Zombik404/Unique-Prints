# Unique prints — копия сайта для своего домена

Полная копия uniqueprints.lovable.app: тот же дизайн, 5 языков (EN, HU, DE, UA, RUS), размеры и цены, студия загрузки и кадрирования фото, корзина, оформление заказа с выбором службы доставки, страница заказа с уникальным номером и кнопкой Telegram, плюс админ-панель.

Блок «Why aluminium» уже с новым текстом на всех 5 языках.

Ничего устанавливать не нужно: обычный PHP-хостинг (PHP 8.0+ с SQLite), без базы MySQL и без npm.

---

## 1. Что нужно от хостинга

- PHP 8.0 или новее (почти у всех хостингов по умолчанию).
- Расширения `pdo_sqlite`, `fileinfo`, `gd` — обычно включены. Проверить можно в панели хостинга в разделе «PHP».
- Apache (подходит большинство shared-хостингов: Hostinger, Beget, Timeweb, Rackhost, Tárhely.eu и т. п.). Для Nginx — см. пункт 6.
- HTTPS (SSL-сертификат). На большинстве хостингов он бесплатный, Let's Encrypt, включается одной кнопкой.

## 2. Установка

1. Распакуйте архив.
2. Загрузите **всё содержимое** папки `uniqueprints` в корень сайта на хостинге (обычно `public_html` или `www`). Через файловый менеджер хостинга или FTP (FileZilla).
   Скрытые файлы `.htaccess` и `.user.ini` тоже нужно загрузить. В FileZilla: «Сервер → Принудительно показывать скрытые файлы».
3. Проверьте, что у папки `data` есть права на запись (755 или 775). Туда сохраняются база заказов и фото клиентов.
4. Откройте файл `api/config.php` и заполните:
   - `admin_password` — пароль для админки, минимум 10 символов;
   - `site_url` — адрес вашего сайта, например `https://uniqueprints.com`;
   - при желании — уведомления о новых заказах (пункт 4).
5. Картинки уже лежат в `assets/img/`: `hero-banner.jpg` (баннер вверху главной) и `detail.webp` (фото в блоке «Почему алюминий»). Чтобы поменять картинку, замените файл, оставив то же имя. Подробнее в `assets/img/README.txt`.
6. Откройте сайт и сделайте тестовый заказ. Потом зайдите в админку и удалите его (кнопка «Удалить заказ» внизу карточки заказа).

## 3. Админ-панель

Адрес: `https://ваш-домен/admin/`

Что умеет:
- **Список заказов**: новые сверху, с миниатюрой, суммой, статусом и отметкой оплаты. Новые заказы помечены точкой, список сам обновляется каждую минуту.
- **Поиск** по номеру заказа (например `UP-261108-K7Q3` или просто `K7Q3`), имени, email, телефону, городу.
- **Фильтры** по статусам и «Не оплачены», со счётчиками.
- **Карточка заказа**: все данные клиента, адрес, служба доставки, пункт выдачи, комментарий клиента.
- **Принты в заказе**: размер, ориентация, количество, цена, качество (dpi), кадр. Две кнопки:
  - **«Файл для печати»** — уже обрезанный по кадру клиента JPEG в полном разрешении, его отдаёте в печать;
  - **«Оригинал»** — исходное фото клиента.
- **Расчёт доставки**: вводите стоимость доставки и видите «принты + доставка = итого». После сохранения статус меняется на «Ждёт оплаты», и клиент видит итоговую сумму на странице своего заказа. Кнопка «Письмо клиенту с суммой» открывает вашу почту с готовым письмом.
- **Оплата отмечается только вручную**: кнопка «Подтвердить оплату» работает после расчёта доставки. Автоматически заказ оплаченным никогда не становится.
- **Статусы**: Ждёт расчёта доставки → Ждёт оплаты → Оплачен → В производстве → Отправлен → Выполнен (или Отменён). Клиент видит текущий статус по своей ссылке.
- **Заметка**: видна только вам.
- **История**: что и когда менялось в заказе.
- **CSV**: выгрузка всех заказов в Excel / Google Таблицы.
- **Место на диске** (кнопка вверху админки) показывает, сколько занимают фото, превью и база, и сколько свободно на сервере. Там же очистка старых заказов: выбираете статусы («Выполнен», «Отменён», «Отправлен») и возраст, например старше 30 дней. Дальше два варианта:
  - **«Удалить только фото»** — удаляет оригиналы, но сам заказ, маленькие превью, данные клиента и история остаются. Освобождает почти всё место.
  - **«Удалить заказы полностью»** — заказы пропадают из админки и CSV вместе с фото.

  Перед удалением админка показывает, сколько заказов и мегабайт будет удалено, и просит подтвердить. Заказы в работе («Ждёт расчёта доставки», «Ждёт оплаты», «Оплачен», «В производстве») очистка не трогает. В карточке любого заказа есть кнопка «Удалить только фото» для этого одного заказа.
- Переключение языка админки: RU / EN.

**Номер заказа** выглядит так: `UP-ГГММДД-XXXX`, например `UP-261108-K7Q3`. Он уникальный, проверяется при создании. Клиент видит его после оформления и одной кнопкой отправляет оператору в Telegram (@UniqueOper). Номер уже подставлен в сообщение.

## 4. Уведомления о новых заказах (по желанию)

**В Telegram:**
1. В Telegram откройте @BotFather → `/newbot` → получите токен.
2. Напишите своему новому боту любое сообщение.
3. Узнайте свой chat id у бота @userinfobot.
4. Впишите в `api/config.php` значения `telegram_bot_token` и `telegram_chat_id`.

Теперь на каждый заказ будет приходить сообщение с номером, составом заказа и ссылкой в админку.

**На почту:** укажите `notify_email`. Работает, если хостинг разрешает PHP `mail()`. Большинство разрешает.

## 5. Что можно менять

Всё в `api/config.php`:
- цены и размеры (`sizes`), в евро;
- валюту для каждого языка сайта (`display_currencies`): сейчас EN — доллары, HU — форинты, DE — евро, UA — гривны, RUS — рубли. Цены задаются и оплачиваются в евро, а посетитель видит их пересчитанными в валюту своего языка. Курс сервер сам берёт раз в сутки с `fx_url` (open.er-api.com, бесплатно, без ключа) и сохраняет в `data/fx.json`. Текущий курс показан в шапке справа. При оформлении и на странице заказа рядом всегда видна сумма в евро. Если источник курса недоступен, используется последний сохранённый курс, а если его ещё нет — `fx_fallback`. Чтобы язык показывал евро без пересчёта, поставьте для него `'EUR'`;
- страны и службы доставки (`shipping`);
- Telegram оператора (`telegram_operator`).

Тексты сайта на всех языках лежат в `assets/js/i18n.js`. Дизайн (цвета, шрифты) — в `assets/css/styles.css`.

## 6. Если у вас Nginx, а не Apache

Добавьте в конфиг сайта:

```nginx
location ^~ /data/ { deny all; }
location ~ ^/api/(config|lib)\.php$ { deny all; }
client_max_body_size 30m;
```

В `php.ini` выставьте `upload_max_filesize = 25M` и `post_max_size = 30M`.

## 7. Безопасность и резервные копии

- Фото клиентов и база хранятся в `data/`. Доступ к этой папке из браузера закрыт. Для ещё большей надёжности папку можно перенести на уровень выше `public_html` и поменять путь `data_dir` в `config.php`.
- Цены всегда пересчитываются на сервере, поэтому клиент не может подменить сумму.
- Вход в админку защищён от подбора пароля: 8 попыток за 15 минут.
- Фото, которые загрузили, но так и не заказали, автоматически удаляются через 3 дня.
- **Делайте резервную копию папки `data/` хотя бы раз в неделю**: там все заказы и фото. Многие хостинги делают бэкапы сами.

## 8. Чем копия отличается от версии на Lovable

- Вход в админку по паролю, а не через Google.
- Вместо AI-оценки фото — автоматическая оценка качества по разрешению: dpi для каждого размера, метки «Отлично / Хорошо / Низкое разрешение». Плюс ручное кадрирование: перетаскивание фото и зум.
- Старые заказы из Lovable в эту копию не переносятся, потому что база там отдельная.
